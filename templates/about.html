About This System

The Scholarship Eligibility Prediction System uses machine learning to evaluate student profiles and recommend relevant Indian scholarship schemes.

How It Works

  1. Input: Enter student details (age, marks, attendance, income, category, etc.)
  2. Prediction: A trained Random Forest model evaluates eligibility and returns a score
  3. Recommendation: The system matches the profile to real Indian scholarship schemes (UGC, AICTE, NSP, etc.)
  4. Output: Get a list of scholarships with award amounts and application links

Technology Stack

Backend
  • Python 3.10
  • Pandas, NumPy
  • Scikit-learn (Random Forest)
  • Flask 3
Frontend
  • HTML5, CSS3
  • Bootstrap 5
